This project compares two algorithms to find the smallest missing positive integer in an array.

## How to Run

1.  **Compile the code**:
    Use a C compiler (like GCC) to compile `main.c`.
   
    gcc main.c -o project
    

2.  **Run the program**:
   
    ./project

    or use code blocks and run Algo project.cbp
  

4.  **Follow the prompts**:
    - Enter the number of elements.
    - Enter the elements (integers) one by one or separated by spaces.

## Project Contents

- `main.c`: The C source code for both algorithms.
- `Missing Integer.pdf`: The project report and complexity analysis.

## Algorithms Included

- **Non-Recursive**: Fast approach using a checklist ($O(N)$).
- **Recursive**: Educational approach using Bubble Sort ($O(N^2)$).
